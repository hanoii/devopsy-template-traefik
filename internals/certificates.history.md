History, not rules: `internals/certificates.md` wins where they differ.

- The resolvers were renamed on 2026-10-27, from `letsencrypt1`, `acmedns` and `cloudflare`, which named a CA, a program and a provider: what a site chooses is how its domain proves control. Dashed names work in `TRAEFIK_CERTIFICATESRESOLVERS_LE-HTTP01_...` (checked on v3.7, 2026-10-27).
- `check_settings` first ran only in `deploy`, the run step: its refusal came after the switch, and the restart of the release before, reading the same `shared/.env`, refused too (seen on a test machine, 2026-10-27). It became the prepare step, `check`.
- A router with `tls.certresolver=` empty, or `tls=true`, gets no certificate at all (checked on v3.7, 2026-10-27), which is why a site leaving the choice to the server has no resolver label.
- Traefik starts with `le-dns01-cloudflare` defined and no token (checked on v3.7.13), failing only a router that uses it.
- There is no "pre-register a domain" command because lego loads `acme-dns-accounts.json` once: each domain would cost a Traefik restart.
- The `init` service went on 2026-10-23 (checked on Traefik v3.7.13 and acme-dns v2.0.2, as 10001 with `cap_drop: [ALL]` and `read_only`, in a 755 directory owned by 10001): Traefik creates `acme-le-http01.json` and the other resolvers' stores with mode 600 at startup (its `local_store.go` opens them with 0600), lego creates `acme-dns-accounts.json` with 0600 (goacmedns' `File`, lego v4.35), and acme-dns creates `acme-dns.db` with mode 600.
- The old `init` also forced 700 on the directories and 600 on the files. The directories are 755 now (new servers; an existing 700 stays), which shows only file names. The one thing `init` did that nothing does now is fix a wider mode: Traefik logs `permissions 644 for /letsencrypt/acme-le-http01.json are too open, please use 600` as an error, the container stays healthy and that resolver is skipped, so only a store restored or copied by hand gets there.
- devopsy gives `mnt/letsencrypt` and `mnt/acmedns` to 10001 through `devopsy.mnt.owner=user`, which takes each service's `user:`, so the two never drift apart: `shared/mnt` starts empty, Docker creates missing bind-mount directories as root, and the deploy user cannot chown to 10001. devopsy makes each entry (755) and gives it and everything in it to 10001 on every release, so files moved in by hand are fixed too.
- The `PROXY_DNS_RESOLVERS` order and the direct check of the authoritative nameservers came from a server behind a corporate resolver, where lego's lookup of the challenge name before writing the record cached NXDOMAIN and the recursive check failed until its negative TTL ended.
- Forgetting needs the `sqlite` service because acme-dns's image has no sqlite and its API no way to remove a registration; the stores are edited through Traefik containers and the `jq` service because neither the host nor the Traefik image has jq, and through the files so they keep the mode 600 Traefik insists on.
